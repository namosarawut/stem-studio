      เริ่มเล่นที่

      เชื่อม Prism กับ Claude (MCP)

      เชื่อมแล้วพิมพ์บอก Claude ได้เลย เช่น "ซ่อมเมโทรนอมให้ตรงกลอง" หรือ "ใส่ cue ก่อนทุกท่อน" Claude จะให้เลือกเพลงจากรายการ แล้วแก้ให้ทันที เพลงที่เปิดอยู่ในหน้านี้จะมีปุ่มให้โหลดใหม่ และสั่ง Claude ให้ย้อนกลับได้

      Claude Desktop
      1. เปิด Claude Desktop ไปที่ Settings → Developer → Edit Config (ไฟล์ )
      2. วางข้อความนี้ ถ้าในไฟล์มี mcpServers อยู่แล้ว ให้เพิ่มเฉพาะส่วน "prism" เข้าไป
      3. บันทึก แล้วปิดเปิด Claude Desktop ใหม่
